# Tính thu hồi cà phê

Trang web tính trừ ẩm & thu hồi cà phê theo **Bảng trừ ẩm cà phê**, tối ưu cho điện thoại.

**Mở trên điện thoại:** https://hovandat2k.github.io/Tinh_thu_hoi/

## Nhập
- Tên mẫu (không bắt buộc)
- KL (g) – bắt buộc
- KL quả (g) – không nhập = 0
- Độ ẩm – bắt buộc (VD `14.5` = 14°5)

## Công thức
Tổng KL = KL + KL quả / 2

**Ẩm < 15:** A = Ẩm / (1 + Ẩm/100) → B = |A − 12.5| → C = B% × Tổng KL → D = Tổng KL ∓ C (trừ nếu A > 12.5, cộng nếu A < 12.5) → Thu hồi = 2000 / D (Kg)

**Ẩm ≥ 15:** A = giá trị bảng trừ ẩm + 0.5 → B = Tổng KL × A% → C = Tổng KL − B → Thu hồi = 2000 / C (Kg)

Kết quả có nút **Sao chép ảnh** (dán vào Zalo, Messenger…), **Chia sẻ**, **Tải ảnh**, **Sao chép dạng chữ**.
